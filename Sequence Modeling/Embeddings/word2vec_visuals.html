1. The Problem: One-Hot vs Dense Embeddings

Traditional One-Hot Encoding

Word One-Hot Vector (Sparse)
fantastic [0, 0, 0, 1, 0, 0, 0, ...]
excellent [0, 0, 0, 0, 1, 0, 0, ...]
terrible [0, 0, 0, 0, 0, 1, 0, ...]

Problem: All words are equally distant! No semantic relationships captured.

Word2Vec Dense Embeddings

Word Dense Vector (Meaningful) Semantic Meaning
fantastic [0.8, 0.9, -0.1, ...] High positive sentiment
excellent [0.7, 0.8, -0.2, ...] Similar to fantastic
terrible [-0.9, -0.8, 0.1, ...] Opposite sentiment

Solution: Similar words have similar vectors! Semantic relationships preserved.

4. Mathematical Foundation

Skip-Gram Objective Function

P(w_context | w_center) = exp(u_center · v_context) / Σ exp(u_center · v_w)

Where:

  • u_center: embedding of center word (from W₁)
  • v_context: context vector (from W₂)
  • Dot product: measures similarity between vectors
  • Softmax: converts scores to probabilities

6. Negative Sampling Illustration

Traditional Softmax vs Negative Sampling

❌ Full Softmax (Slow)

Compute probability for ALL vocabulary words:

exp(cat·the) / Σexp(cat·word) for ALL words in vocabulary (computationally expensive!)

✅ Negative Sampling (Fast)

Only compute for few sampled words:

Positive: σ(cat·the) → 1 Negative: σ(cat·car) → 0 Negative: σ(cat·xyz) → 0 (much faster!)
Key Insight: Instead of computing probabilities for all 50,000+ words, we only need to distinguish the correct word from 5-20 random "negative" examples.

9. Implementation Code Snippets

Core Forward Pass

# 1. Embedding Lookup center_embedding = W1[center_word_idx, :] # Get word vector # 2. Compute Similarity Scores scores = np.dot(center_embedding, W2) # Dot product with all context vectors # 3. Convert to Probabilities probabilities = softmax(scores) # Normalize to probability distribution

Gradient Update

# Compute gradient grad_scores = probabilities - target_one_hot # Update weights W2 -= learning_rate * np.outer(center_embedding, grad_scores) W1[center_word_idx] -= learning_rate * np.dot(W2, grad_scores)

🎯 Key Takeaway

Word2Vec transforms the fundamental problem of understanding language from sparse symbolic representation to dense geometric relationships, where semantic similarity becomes spatial proximity in vector space.
